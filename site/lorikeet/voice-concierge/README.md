# Voice concierge

**What it is:** Meridian Voice Concierge, an AI voice concierge handling a stolen card call end to end: verification, policy guardrails, card replacement and a human handoff. A second act shows the eval log catching a real failure and a fix proving it out.

**Built for:** Lorikeet.

**What it proves:** I can think through a regulated support flow the way their customers would, including how you catch and fix the agent when it gets something wrong.

**Live:** https://lorikeet-voice-concierge-demo.pages.dev

Single static `index.html`, copied from the deployed version. Unofficial concept, mock data only, no Lorikeet brand assets.
