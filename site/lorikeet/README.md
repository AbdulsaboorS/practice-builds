# Lorikeet

Lorikeet builds AI customer support agents. I built two things for them.

- [reg-e-test-pack](reg-e-test-pack/): tested an AI support agent on 17 disputed-payment calls under Regulation E. The agent mostly knew the rules. The SOP it was handed broke them. Live: https://reg-e-test-pack.pages.dev
- [voice-concierge](voice-concierge/): an AI voice concierge handling a stolen card call end to end, plus an eval log that catches a real failure and the fix. Live: https://lorikeet-voice-concierge-demo.pages.dev

Both are unofficial concepts with mock data only. Not affiliated with Lorikeet.
