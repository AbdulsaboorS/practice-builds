Hear It at Your Practice

Built for Prosper AI. Concept demo, not affiliated. Sample calls are scripted with mock data. No PHI.

On Prosper's site, a potential customer can hear one agent recording, and it isn't about their practice. So I built a demo that is: enter a practice name and specialty, and every Prosper agent plays a short call for that practice in its own voice. Booking a demo carries over which agents the visitor listened to, so the sales team knows where to start.

My first two weeks: polish it and A/B test it against today's experience, measuring demo requests and which agents visitors play.

The live app generates its voices on Cloudflare (Deepgram Aura-2 on Workers AI), so it runs on its own deployment.
