# Hear It at Your Practice

**What it is:** enter a practice name and specialty, and every Prosper agent plays a short sample call for that practice in its own voice. Booking a demo carries over which agents the visitor listened to.

**Built for:** Prosper AI (healthcare voice agents). Concept demo, not affiliated. Scripted calls with mock data, no PHI.

**What it proves:** I can find a gap in a company's funnel (one generic agent recording on their site) and ship a personalized fix in an evening, with a plan to A/B test it.

**Live:** https://prosper-hear-it.pages.dev
**Code:** https://github.com/AbdulsaboorS/prosper-hear-it

The app uses a Cloudflare Pages Function for text-to-speech, so it runs on its own deployment. This folder holds a landing page and the demo video.
