FairHouse AI

Agentic Enterprise AI Hackathon with Box + AWS, Seattle, Oct 2026. Placed 2nd. Team project.

AI that checks affordable-housing tenant income files for the Seattle Office of Housing, with the proof highlighted, so every file can be reviewed every year under the same rules. Today the city typically reviews files only every 3 years, and only a 20% sample.

  1. Read: tenant documents land in a Box folder and the text is extracted.
  2. Extract: Claude on AWS Bedrock pulls out wages, deposits and benefits, each with its exact quote and page.
  3. Calculate: plain code applies the city's formula. No AI in the math.
  4. Validate: Claude checks for missing documents, mismatches and suspicious items.
  5. Explain: the reviewer walks through each step with the source highlighted and approves with Box Sign.
