# FairHouse AI

**What it is:** AI that checks affordable-housing tenant income files for the Seattle Office of Housing, with the proof highlighted, and a human reviewer approving through Box Sign.

**Built for:** the Agentic Enterprise AI Hackathon with Box + AWS, Seattle, Oct 2026. Placed 2nd. Team project.

**What it proves:** I can take a messy, regulated review process and design an AI flow people can trust: AI reads and extracts, plain code does the math, a human decides.

**Code:** https://github.com/seapeppers/fairHouseAi
**Demo:** the video on this folder's page. There's no hosted version.

All tenant files are synthetic.
